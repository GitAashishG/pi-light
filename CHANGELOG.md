# Changelog

## 0.1.0 — 2026-11-19

- Added USB status indication on the original Particle Photon: blue for work, amber for input, green for completion, and red for run errors.
- Added a macOS bridge with session priority, expiring leases, USB reconnects, and a firmware heartbeat watchdog.
- Added the OMP extension, installer, diagnostic CLI, and hardware-free tests. Continuing background jobs keep the light blue until the run finishes.
